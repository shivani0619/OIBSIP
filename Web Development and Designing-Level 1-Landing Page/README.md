
# CreativeSpace – Landing Page

## Project Overview
CreativeSpace is a responsive landing page developed as part of the Oasis Infobyte Web Development and Designing internship, Level 1 Task 1.

The website introduces a creative platform through a modern layout, clear navigation, and attractive design.

## Features
- Sticky navigation bar with Home, About, Services, and Contact links
- Hero section with a headline and call-to-action button
- About section introducing CreativeSpace
- Services section with three feature cards
- Contact section with an email link
- Footer with social media links
- Smooth scrolling navigation
- Responsive layout for desktop and mobile screens

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Alternatively, use the Live Server extension in Visual Studio Code.

## Project Structure
- `index.html` – Website structure
- `style.css` – Styling and responsive layout
- `README.md` – Project documentation
- `screenshots/` – Project screenshots
